01 / LOOKUP
Salary in, contribution out.
The page sends the membership type, the month and the salary (or chosen MSC). The API returns the row of the SSS table that applied that month, with each payer's share.
02 / REVERSE LOOKUP
Amount in, salary credit out.
Enter a payslip deduction, employer share, total or member payment. The API returns the salary credit and salary range that produce it. A few household amounts match more than one row, and the page shows them all.
03 / YOUR DATA
Sent to the API, not stored here.
Lookups need internet. The amounts you enter are sent to the public API at api.nocodebackend.com. This page keeps no accounts, cookies or analytics. For fully offline use, try the offline calculator.

    
A reference sample, with a clear scope. Uses the public API's 2023 and 2025 official tables. A reverse lookup estimates monthly compensation from one employer; it is not proof of income.
